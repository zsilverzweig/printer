# Printer

An AI-powered investment research engine that produces actionable, company-level investment theses through structured reasoning and adversarial testing.

## Overview

Printer is a virtual investment firm powered by AI agents that work together to analyze companies, build investment theses, and manage portfolios. The system uses multi-agent collaboration, persistent context, and continuous learning to make investment decisions that improve over time.

## Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

## Key Features

- **🤖 Multi-Agent System** - Specialized AI agents for investment analysis
- **📊 Structured Decision Cycles** - Thesis + catalyst + time horizon for every position
- **⚔️ Adversarial Testing** - Built-in counterpoint analysis for every investment thesis
- **📈 Performance Tracking** - Continuous monitoring and system improvement
- **💻 Real-time Interface** - Web-based dashboard for monitoring and control
